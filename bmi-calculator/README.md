# BMI Calculator

**Notebook:** [bmi_calculator.ipynb](bmi_calculator.ipynb)
**Tools:** Python

## What it does
Asks for a name, weight (lbs), and height (inches), then calculates BMI using the
[CDC adult formula](https://www.cdc.gov/healthyweight/assessing/bmi/adult_bmi/english_bmi_calculator/bmi_calculator.html):

```
BMI = (weight in lbs × 703) / (height in inches)²
```

It then reports the matching category (underweight, healthy, overweight, obese)
and rejects invalid input.
